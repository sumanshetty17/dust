Copy this code and paste it just before the closing </body> tag of your website. The chat bubble then appears on every page.



How do I add it on WordPress, Wix, Shopify…?


WordPress: install the free "WPCode" plugin → Code Snippets → Add Snippet → HTML Snippet → paste → Insert: Site Wide Footer → Active.


Shopify: Online Store → Themes → ⋯ → Edit code → theme.liquid → paste above </body> → Save.


Wix: Settings → Custom Code → Add Code → paste → Place in: Body – end → All pages (may need a premium plan).


Squarespace: Settings → Advanced → Code Injection → Footer → paste (needs a paid plan).


Webflow: Project Settings → Custom Code → Footer Code → paste → Publish.


Plain HTML: paste above </body> in each page, or in your shared footer file. Hand it to your web developer if unsure: it's one line.
